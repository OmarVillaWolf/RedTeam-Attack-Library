# Introducción 

Tags: #Web 

## Objetivos: 

- **Identificación de activos:** Descubrir todos los componentes del objetivo que son accesibles públicamente, como páginas web, subdominios, direcciones IP y las tecnologías utilizadas. Este paso proporciona una visión completa de la presencia en línea del objetivo.
- **Descubrimiento de información oculta:** Localizar información sensible que pueda haber sido expuesta de manera involuntaria, como archivos de respaldo, archivos de configuración o documentación interna. Estos hallazgos pueden revelar información valiosa y posibles puntos de entrada para futuros ataques.
- **Análisis de la superficie de ataque:** Examinar la superficie de ataque del objetivo para identificar posibles vulnerabilidades y debilidades. Esto implica evaluar las tecnologías utilizadas, las configuraciones implementadas y los posibles vectores de entrada que podrían ser explotados.
- **Recopilación de inteligencia:** Obtener información que pueda aprovecharse en etapas posteriores de explotación o en ataques de ingeniería social. Esto incluye identificar personal clave, direcciones de correo electrónico o patrones de comportamiento que puedan ser utilizados por un atacante.

## Reconocimiento Activo 

| **Technique**              | **Description**                                                                                 | **Example**                                                                                                                               | **Tools**                                   | **Risk of Detection**                                                                                                     |
| -------------------------- | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Port Scanning**          | Identifica los puertos abiertos y los servicios que se ejecutan en el objetivo.                 | Utilizar Nmap para escanear un servidor web e identificar puertos abiertos como **80 (HTTP)** y **443 (HTTPS)**.                          | Nmap, Masscan, Unicornscan                  | 🔴 **Alto:** La interacción directa con el objetivo puede activar sistemas de detección de intrusiones (IDS) y firewalls. |
| **Vulnerability Scanning** | Busca vulnerabilidades conocidas, como software desactualizado o configuraciones incorrectas.   | Ejecutar Nessus contra una aplicación web para detectar vulnerabilidades como **SQL Injection** o **Cross-Site Scripting (XSS)**.         | Nessus, OpenVAS, Nikto                      | 🔴 **Alto:** Los escáneres envían cargas de prueba que pueden ser detectadas por soluciones de seguridad.                 |
| **Network Mapping**        | Mapea la topología de la red del objetivo, incluyendo dispositivos conectados y sus relaciones. | Utilizar `traceroute` para determinar la ruta que siguen los paquetes hasta el servidor objetivo e identificar la infraestructura de red. | Traceroute, Nmap                            | 🟠 **Medio-Alto:** Un tráfico excesivo o inusual puede levantar sospechas.                                                |
| **Banner Grabbing**        | Obtiene información a partir de los banners mostrados por los servicios del objetivo.           | Conectarse a un servidor web en el puerto **80** y analizar el banner HTTP para identificar el software y su versión.                     | Netcat, curl                                | 🟢 **Bajo:** Requiere poca interacción, aunque las conexiones pueden quedar registradas en los logs.                      |
| **OS Fingerprinting**      | Identifica el sistema operativo que ejecuta el objetivo.                                        | Utilizar la detección de sistema operativo de Nmap (`-O`) para determinar si el objetivo utiliza Windows, Linux u otro SO.                | Nmap, Xprobe2                               | 🟢 **Bajo:** Generalmente es poco intrusivo, aunque algunas técnicas avanzadas pueden ser detectadas.                     |
| **Service Enumeration**    | Determina las versiones específicas de los servicios que se ejecutan en los puertos abiertos.   | Utilizar la detección de versiones de Nmap (`-sV`) para identificar si el servidor ejecuta **Apache 2.4.50** o **Nginx 1.18.0**.          | Nmap                                        | 🟢 **Bajo:** Similar al Banner Grabbing; suele registrarse en logs, pero rara vez genera alertas.                         |
| **Web Spidering**          | Rastrea un sitio web para descubrir páginas, directorios y archivos.                            | Ejecutar un crawler como **Burp Suite Spider** u **OWASP ZAP Spider** para mapear la estructura del sitio y descubrir recursos ocultos.   | Burp Suite Spider, OWASP ZAP Spider, Scrapy | 🟡 **Bajo-Medio:** Puede detectarse si el comportamiento del crawler no imita el tráfico legítimo.                        |

## Reconocimiento Pasivo 

|**Technique**|**Description**|**Example**|**Tools**|**Risk of Detection**|
|---|---|---|---|---|
|**Search Engine Queries**|Utiliza motores de búsqueda para recopilar información sobre el objetivo, como sitios web, perfiles en redes sociales y artículos de noticias.|Buscar en Google **"[Nombre del objetivo] employees"** para encontrar información de empleados o perfiles en redes sociales.|Google, DuckDuckGo, Bing, Shodan|🟢 **Muy Bajo:** Las búsquedas en motores de búsqueda son una actividad normal en Internet y es muy poco probable que generen alertas.|
|**WHOIS Lookups**|Consulta bases de datos WHOIS para obtener información sobre el registro de un dominio.|Realizar una consulta WHOIS sobre un dominio para obtener el nombre del registrante, información de contacto y servidores DNS (Name Servers).|`whois`, servicios web de WHOIS|🟢 **Muy Bajo:** Las consultas WHOIS son completamente legítimas y no generan sospechas.|
|**DNS Enumeration**|Analiza los registros DNS para identificar subdominios, servidores de correo y otros componentes de la infraestructura.|Utilizar `dig` para enumerar los subdominios de un dominio objetivo.|`dig`, `nslookup`, `host`, `dnsenum`, `fierce`, `dnsrecon`|🟢 **Muy Bajo:** Las consultas DNS son fundamentales para el funcionamiento de Internet y normalmente no se consideran sospechosas.|
|**Web Archive Analysis**|Examina versiones históricas del sitio web del objetivo para identificar cambios, información oculta o posibles vulnerabilidades.|Utilizar **Wayback Machine** para visualizar versiones anteriores del sitio web y analizar su evolución.|Wayback Machine|🟢 **Muy Bajo:** Consultar sitios archivados es una actividad completamente normal.|
|**Social Media Analysis**|Recopila información pública de plataformas como LinkedIn, X (Twitter) o Facebook.|Buscar empleados de una organización en LinkedIn para conocer sus funciones, responsabilidades y posibles objetivos de ingeniería social.|LinkedIn, X (Twitter), Facebook, herramientas OSINT|🟢 **Muy Bajo:** Acceder a perfiles públicos no se considera una actividad intrusiva.|
|**Code Repositories**|Analiza repositorios públicos de código para descubrir credenciales expuestas, secretos o vulnerabilidades.|Buscar en GitHub repositorios relacionados con el objetivo que puedan contener credenciales, claves API o información sensible.|GitHub, GitLab|🟢 **Muy Bajo:** Los repositorios públicos están diseñados para ser accesibles y consultarlos no suele generar sospechas.|
