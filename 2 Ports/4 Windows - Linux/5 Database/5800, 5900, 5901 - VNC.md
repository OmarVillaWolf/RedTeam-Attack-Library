# Virtual Network Computing (VNC)

Tags: #VNC 

VNC (_Virtual Network Computing_) permite **ver y controlar el escritorio de otra computadora a través de la red**: transmite la pantalla y envía las acciones de teclado y ratón.

Se usa para soporte remoto, administrar equipos o acceder a un escritorio gráfico. Normalmente hay un servidor VNC en la máquina remota y un cliente VNC en la tuya. La conexión puede requerir contraseña y conviene protegerla con una red segura o un túnel, porque la seguridad depende de la configuración del servidor y del cifrado disponible.

```bash 
# Se necesita una paassword válida para iniciar el servicio remoto 

❯ vncviewer <IP>            # Iniciar el servicio vnc 
❯ vncviewer 127.0.0.1:5901  # Iniciar el servicio vnc
```
