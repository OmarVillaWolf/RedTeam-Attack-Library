## Comandos 

```bash
❯ mongo -u ❮USER❯ -p ❮PASSWD❯ ❮HOST❯ # Nos conectaremos a mongo DB en la parte de scheduler, si sale un error como el siguiente: 'Failed global initialization' colocamos el siguiente comando 'export LC_ALL=C'
```

```bash
❯ mongo                        # Conectar a mongo 
Una vez dentro de mongo hacemos lo siguiente 	
	❯ help                    # Mirar que comando se puede usar para listar la DB 
	❯ show dbs                # Listar las DB
	❯ use blog                # Usar la base de datos llamada 'blog' 
	❯ show collections        # Mostrar contenido y encontramos users
	❯ db.users.find()         # Listar el contenido y encontrar credenciales 
	❯ bye                     # Salir de mongo
```

## Otra forma de hacerlo 

```bash
❯ mongodump                    # Crear el directorio dump  
❯ ls                           # Listar el contenido creado
❯ cd dump/                     # Ir al directorio dump y mirar toda la información 
❯ cd blog/                     # Ingresar al directorio blog y mirar los archivos en formato bson 
❯ bsondump users.bson          # Mirar las credenciales  
```
