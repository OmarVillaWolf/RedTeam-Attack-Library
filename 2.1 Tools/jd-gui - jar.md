# JD-GUI

Tags: #Jd-gui

JD-GUI es una utilidad gráfica diseñada para descompilar y analizar archivos .class y .jar de Java. Permite visualizar el código fuente Java original a partir de bytecode, facilitando la depuración, auditorías de seguridad y la ingeniería inversa, mostrando el código estructurado en una interfaz intuitiva.

```bash 
❯ apt install jd-gui     # Instalar jd-gui
❯ jd-gui                 # Inicializar 
```
