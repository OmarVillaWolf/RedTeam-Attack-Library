# Rubeus 

Tags: #MovimientoLateral #Windows #Server 

Herramienta escrita en C# especializada en Kerberos. Permite realizar operaciones con tickets TGT y TGS, solicitar tickets, inspeccionar sesiones y evaluar configuraciones de autenticación en Active Directory.

Requisitos:
- Sistema Windows compatible.
- Binario compilado o compilación desde el código fuente.
- .NET Framework compatible: la versión clásica utiliza .NET 3.5; versiones posteriores del código utilizan .NET 4.0 o superior.
- Conectividad y contexto de dominio para las operaciones que interactúan con el KDC.
- Algunas funciones requieren credenciales, tickets o privilegios específicos.
