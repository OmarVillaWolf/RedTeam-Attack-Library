# Gemini-Cli 

Tags: #Gemini-Cli

## Comandos 

```bash 
❯ gemini-cli -v       # Versión de Gemini
❯ gemini-cli -h       # Panel de ayuda de los comandos 
```

```bash 
❯ gemini-cli -p "Escribir un prompt"            # Ejecuta lo que le compartes y finaliza la interacción 
❯ gemini-cli -i                                 # Modo interactivo 
❯ gemini-cli -i "Escribir un prompt" --yolo     # Modo interactivo más el modo 'yolo' que se salta el preguntar si se quieren ejecutar las herramientas. Solo se debe escribir 'continuar'
```
