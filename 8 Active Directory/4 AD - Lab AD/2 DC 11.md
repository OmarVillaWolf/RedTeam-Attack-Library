# Enumeración inicial del DC 11

Tags: #AD #Kali 

## Fase 1: Enumeración de usuarios 

```bash 
❯ nxc smb <IP> --users    
# Enumerar usuarios 

❯ nxc smb <IP> --pass-pol
# Enumerar políticas de contraseñas 

❯ enum4linux <IP>
# No requiere creds → enum legacy (puede fallar en AD modernos)

❯ rpcclient -U "" <IP> -N
❯ rpcclient -U "Domain01\\" <IP> -N
# Fuerza null sin password (útil cuando pide pass)

❯ net rpc group members 'Domain Users' -W 'DOMAIN01' -I 'IP' -U '%'    # Enumerar todos los usuarios del dominio 

❯ nmap -p 88 --script=krb5-enum-users --script-args="krb5-enum-users.realm='Domain01.local',userdb=users.txt" <IP>
# Utiliza el script krb5-enum-users de Nmap para enumerar usuarios válidos en el dominio mediante el servicio Kerberos (puerto 88). El script envía solicitudes AS-REQ y analiza las respuestas del KDC para determinar la existencia de usuarios.

❯ kerbrute userenum -d domain.corp --dc <IP> users.txt
# No requiere creds → valida usuarios contra el DC directamente vía Kerberos
# Más sigiloso que LDAP o RPC para enumerar usuarios

❯ nxc smb <IP> -u users.txt -p passwd.txt --continue-on-success --no-bruteforce
# Paraleliza pruebas (más rápido)
# --no-bruteforce → probar de forma paralela los diccionario
```
