# Tipos de auditoría 

Tags: #AD 

```bash 
1. Auditoría externa: No se dispone de acceso lógico o físico a la infraestructura de red de la organización. 
  
2. Auditoría interna: Se dispone de acceso lógico (ej. VPN) o físico (instalaciones del cliente) a la infraestructura de la red de la organización.
  - Sin credenciales de usuario de dominio
  - Con credenciales de usuario de dominio 
	* Credenciales de usuario 'sin privilegios'
	* Credenciales de usuario 'privilegiado' 

El mas común es una audirotía interna con credenciales de usuario sin privilegios.
```
