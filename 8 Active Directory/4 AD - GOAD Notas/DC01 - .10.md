## Fase 1: Enumeración de usuarios fuera del server 

```bash 
❯ nmap -p 88 --script=krb5-enum-users --script-args="krb5-enum-users.realm='Domain01.local',userdb=users.txt" <IP>
# Utiliza el script krb5-enum-users de Nmap para enumerar usuarios válidos en el dominio mediante el servicio Kerberos (puerto 88). El script envía solicitudes AS-REQ y analiza las respuestas del KDC para determinar la existencia de usuarios.
```
